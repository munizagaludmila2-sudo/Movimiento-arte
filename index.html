✨ Cooperativa de danza

Nuestra Cooperativa

Un espacio donde la danza no solo es una actividad para aprender: también es un lugar para divertirse, comprenderse, compartir y crecer juntos.

Conocer el proyecto ↓

¿Qué hacemos?

Producimos y compartimos arte, organizamos actividades culturales, promovemos el movimiento y la expresión y trabajamos en equipo. Buscamos que la danza sea una actividad accesible e inclusiva.

💃

Arte y danza

Aprendemos, practicamos y compartimos diferentes expresiones artísticas.

🤝

Trabajo colectivo

Distribuimos tareas y responsabilidades para alcanzar objetivos comunes.

🌱

Inclusión

Queremos un espacio donde las personas puedan participar, compartir y crecer.

🎭

Actividades culturales

Organizamos encuentros y propuestas para difundir el arte y la cultura.

📣

Difusión

Comunicamos clases, horarios y actividades mediante redes sociales.

💜

Comunidad

Buscamos beneficiar a los socios y también aportar a la comunidad.

“Bailamos juntos y crecemos juntos.”

Objetivos y recursos

🎯 Nuestro objetivo

Ofrecer un espacio accesible para aprender danza, fomentando también la integración y el compañerismo.

  • Generar un espacio de trabajo colectivo.
  • Difundir el arte y la cultura.
  • Fomentar el movimiento y la inclusión.
  • Lograr un desarrollo sostenible.
  • Beneficiar a los socios y a la comunidad.

🧰 Lo que necesitamos

  • Salón para realizar las clases.
  • Equipo de música.
  • Espejos para poder practicar.
  • Elementos de limpieza.
  • Agua para los alumnos.
  • Dispensers.
  • Celulares y computadoras para organizarnos.
  • Redes sociales.
  • Dinero para gastos iniciales.
  • Batería para preparar las clases y coreografías.

Organización

¿Cómo comenzamos?

💵

Aporte inicial

Cada integrante puede realizar un aporte inicial de dinero para comenzar el proyecto.

🏢

Gastos principales

El dinero se utilizará para cubrir gastos de la cooperativa, como el alquiler del salón y elementos de publicidad.

💡

¿Y después?

Con el dinero recaudado se podrán pagar servicios del salón, luz y otros gastos necesarios.

⚖️

¿Qué queda?

Lo que quede se repartirá en partes iguales para cada integrante.
